# Book House

A book rental website built with PHP and MySQL. Users can add books, rent them, pay, and return them. Late returns are charged a penalty.

## Technology
HTML, CSS, JavaScript, PHP, MySQL (XAMPP)

## Features
- User register and login
- Add, edit and delete your own books
- Rent a book and pay
- Return a book (Rs. 10 penalty per late day)
- Rented books show "Rented" with the date they are free again
- Admin login: view users, books and payments, block or unblock users

## How to run
1. Install XAMPP and start Apache and MySQL.
2. Copy this project folder into `C:\xampp\htdocs\`.
3. Open phpMyAdmin, create a database named `book_house`, and import `book_house.sql`.
4. Open http://localhost/book_house/index.html
